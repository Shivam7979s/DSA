# Contributing to DSA Solutions

Thank you for your interest in contributing to this repository! Here's how you can help.

## 📋 Contribution Guidelines

### Adding a New Solution

1. **Create a new folder** for the problem:
   ```
   <problem-number>-<problem-name>/
   ```
   Example: `100-same-tree/`

2. **Add Solution.java** with:
   - Clear, commented code
   - Proper variable naming
   - Time/Space complexity analysis

3. **Add README.md** with:
   - Problem description
   - Examples
   - Approach explanation
   - Complexity analysis
   - Key insights/tips

### Example Structure
```
1013-fibonacci-number/
├── Solution.java
└── README.md
```

### Code Standards
- Use proper Java naming conventions
- Add comments for complex logic
- Include edge case handling
- Optimize for both time and space

### README Template
```markdown
# Problem Title

**LeetCode Link**: [Link](https://leetcode.com/problems/...)  
**Difficulty**: Easy/Medium/Hard

## Problem Statement
[Brief description of the problem]

## Examples
```
Input: ...
Output: ...
```

## Approach
[Explanation of your solution approach]

## Complexity Analysis
- Time: O(...)
- Space: O(...)

## Key Insights
- Point 1
- Point 2
```

## 🚀 How to Submit

1. Fork the repository
2. Create a branch: `git checkout -b add/problem-name`
3. Add your solution following the guidelines
4. Commit: `git commit -m "Add solution for problem XXX"`
5. Push: `git push origin add/problem-name`
6. Open a Pull Request

## ✅ Code Review Checklist

- [ ] Code is clean and well-commented
- [ ] Solution is optimized (no unnecessary iterations)
- [ ] README is comprehensive
- [ ] Examples are correct
- [ ] Complexity analysis is accurate
- [ ] Edge cases are handled

## 💬 Suggestions & Feedback

Have ideas for improvement?
- Open an Issue
- Suggest optimizations
- Point out edge cases
- Recommend better approaches
